# Хтось на скіл

Скіли для Root & Claw, написані в Markdown.

- `skill-create-json-character` — створює JSON-персонажа модуля, імпортує на сайт.
- `skill-create-worldshot` — створює розділ (worldshot або компанію) в окремій папці, задає запитання, опорядковує локації, фракції, істот, карту світу, залишає інструкції моделі.
- `skill-write-chapter-for-world` — пише конкретну главу в компанії або наповнює ваншот контентом, ранжує бойовики, загадки, соціальні сцени, дослідження, розраховує 4–5 ігрових годин, зрозуміло, чи доповнює існуючу главу, а чи створює нову.

Усі скіли посилаються на модуль Root & Claw та базову книгу игрока, задають запитання, пишуть російською, не вигадують налаштування замість користувача.
