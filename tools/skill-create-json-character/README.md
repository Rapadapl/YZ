# Скилл JSON-персонажа

`skill.md` — навык, который собирает персонажа Root & Claw в файл, понятный
листу на сайте.

## Что делает

- Задаёт только те вопросы, без которых не заполнить файл: вариант, линия,
  характеристики, навыки, мутации, аура, звериные черты, крайности характера,
  снаряжение, имя.
- Пишет JSON в формате, который `year-zero-srd/character.html` действительно
  импортирует: `version`, `variant`, `fields`, `tracks` — с плоскими ключами
  вроде `chars.body.value` и `skills.stealth.rank`.
- Знает девять линий с самоназваниями, двенадцать навыков с их id на листе и
  настоящие цены опыта: новый навык — 5 опыта, специализация — 5 / 10 / 15 / 20
  за D / C / B / A.

## Как пользоваться

1. Попросите персонажа словами: «собери енота-взломщика, две био-мутации,
   светлая аура».
2. Ответьте на вопросы, которых не хватает.
3. Возьмите готовый файл из `characters/`.
4. Откройте `character.html`, нажмите «Импорт» и выберите файл.

## Чего скилл не делает

- Не выдумывает имя, линию или мутацию за пользователя.
- Не обещает, что новый навык появится на листе отдельной строкой: на листе
  двенадцать базовых навыков и колонка специализации, поэтому свой навык
  записывается в специализацию ближайшего базового или в заметки.
- Не ссылается на бестиарий: такого файла в проекте нет.

Факты о системе лежат в `tools/root-and-claw/reference/rules-map.md` — скилл
сверяется с ним, а не с памятью.
