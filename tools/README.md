# инструменты

Набор скиллов и справочников, которые помогают работать с проектом.

## Справочники

`tools/root-and-claw/reference/` — общая база для всех трёх скиллов.

- `rules-map.md` — факты системы: девять линий с самоназваниями, характеристики,
  двенадцать навыков с id на листе, опыт и специализации, мутации, аура,
  нагрузка, магия и паника, карта файлов проекта, формат JSON персонажа.
- `world-contract.md` — общий контракт мира: папка мира и имена файлов, язык,
  ссылки на источники, порядок вопросов, ранжирование сцен, объём на 4–5
  игровых часов, блок заметок для модели, продолжение или новая глава.

## Создать JSON-персонажа

`tools/skill-create-json-character/skill.md` — создаёт файл персонажа в формате,
который импортирует `year-zero-srd/character.html`.

Читайте `tools/skill-create-json-character/README.md` для понимания, как
пользоваться.

## Создать worldshot или компанию

`tools/skill-create-worldshot/skill.md` — создаёт мир отдельной папкой: локации,
фракции, существа, карту текстом, README и заметки для модели. Соблюдает
`world-contract.md`.

## Написать главу или наполнить worldshot

`tools/skill-write-chapter-for-world/skill.md` — пишет главу или наполняет
worldshot: ранжирует бой, загадку, социальную сцену и исследование, считает
4–5 игровых часов, понимает, продолжает ли он главу или создаёт новую. Соблюдает
`world-contract.md`.

## Навигация

- `tools/root-and-claw/reference/` — общие справочники.
- `tools/skill-create-json-character/` — скилл JSON-персонажа.
- `tools/skill-create-worldshot/` — скилл мира.
- `tools/skill-write-chapter-for-world/` — скилл главы.

## Разработка

Новый скилл кладите в отдельный каталог `skill-<slug>/` с `skill.md` внутри. Если
скилл опирается на общие правила, он ссылается на `root-and-claw/reference/`, а не
переписывает их у себя. Если скилл достойный, добавьте README в каталог и строку
в этот файл.
