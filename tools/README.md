# инструменты

Набор скриптов и утилит, которые помогают работать с проектом.

## Создать JSON-персонажа

`tools/skill-create-json-character/skill.md` — описание навыка, который создаёт JSON-персонажа для модуля Root & Claw и импортирует его на сайт.

Читайте `tools/skill-create-json-character/README.md` для понимания, как пользоваться.

## Создать worldshot или компанию

`tools/skill-create-worldshot/skill.md` — навык для создания worldshot, компании, локации, фракций, существ, карты мира в отдельной папке проекта. Задаёт вопросы, ссылается на Root & Claw и базовую книгу игрока, пишет на русском, оставляет инструкции модели.

## Написать главу или наполнить worldshot

`tools/skill-write-chapter-for-world/skill.md` — навык для написания главы или наполнения worldshot контентом. Задаёт вопросы, ранжирует бой, загадку, социальное и исследование, пишет главу на 4–5 игровых часов, понимает, продолжает ли он existing главу или создаёт новую, ссылается на модуль и базовую книгу, пишет на русском.

## Навигация

- `tools/skill-create-json-character/` — каталог со скиллом создания JSON-персонажа.
- `tools/skill-create-worldshot/` — каталог со скиллом worldshot.
- `tools/skill-write-chapter-for-world/` — каталог со скиллом написания главы.

## Разработка

Когда добавляете новый скилл, кладите его в отдельный каталог с именем `skill-<slug>/` и создавайте `skill.md` внутри. Если скилл достойный, можно добавить README в каталог и в `tools/README.md`.
