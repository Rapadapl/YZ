# Root & Claw — Reference Document Overview

This folder contains the complete Root & Claw rules reference, split into convenient .md files for easy reading.

## File Structure

- `01-introduction.md` - Core concepts, accessibility, speed, risk/reward, wounds, edges, d66 tables
- `02-player-characters.md` - Character creation, attributes, archetypes, skills, equipment, experience
- `03-skills-specializations.md` - 12 basic skills, checks (classic vs modern), advantages/penalties, special efforts
- `04-combat-damage.md` - Combat resolution, cards/zones, initiative, turns, firearms, close combat, damage, armor, conditions, wounds
- `05-magic.md` - Magic traditions (7 traditions), spell creation, risk, enhancement, side effects, rituals
- `06-travel.md` - Travel rules, terrain types, random encounters, weather, movement, rest, exploration

## How to Use

Each file contains the key rules from that chapter. 
Read them in order for a complete understanding, or reference individual files as needed.
